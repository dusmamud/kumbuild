# backend/orders

Order create, order status (received -> in progress -> preview -> delivered), order tracking, revisions.

Order WhatsApp / Instagram DM / form se aata hai; confirm hone ke baad admin use khud `admin.kumbuild.com/orders` me add karega aur saari progress wahin track karega. Customer ko status WhatsApp pe bataya jayega — customer ka koi dashboard nahi hai.
